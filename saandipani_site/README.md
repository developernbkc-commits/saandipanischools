# Saandipani International Schools website

This folder contains a static, multi-page website prepared for Netlify deployment.

## Contents

- Static HTML pages with clean directory-based URLs
- `assets/css/styles.css` and `assets/js/main.js`
- HTML sitemap page at `/sitemap/`
- XML sitemap at `/sitemap.xml`
- `robots.txt`
- `site.webmanifest`
- `netlify.toml`
- Netlify-ready admissions enquiry form at `/admissions/enquiry/`

## Notes

- The website uses the thinner-stem Saandipani logo.
- The design language blends the business card minimalism with the brochure palette and messaging.
- The five-layer-deep path is:
  `/montessori/foundations/prepared-environment/classroom-flow/parent-guide/`

## Deployment

- Manual deploy: upload the project folder to Netlify.
- Git deploy: connect the repository in Netlify and use the included `netlify.toml`.
- The site is static, so no build command is required for this package.
- The admissions form is configured as a static HTML Netlify form.
