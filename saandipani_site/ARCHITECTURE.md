# Saandipani website architecture

This package is a static, multi-page website designed for Netlify deployment.

## Design direction

- Premium Montessori visual language
- Thin-stem Saandipani logo
- Business-card minimalism with brochure colors and curved shapes
- Parent-first lead conversion flow
- No orphan public pages
- Five-layer-deep navigation path:
  `/montessori/foundations/prepared-environment/classroom-flow/parent-guide/`

## Public sections

- Home
- About
- Montessori
- Programs
- Admissions
- Campus
- Parents & Families
- Journal
- Contact
- HTML Sitemap

## Conversion strategy

Every page routes visitors toward at least one of these next steps:

- Explore Montessori
- Check program fit
- Read parent guidance
- Start an admissions enquiry
- Contact the school

## Internal-linking strategy

Public pages are linked through:

1. Global header navigation
2. Footer navigation
3. Section navigation blocks
4. Breadcrumbs
5. Related exploration cards
6. CTA bands
7. HTML sitemap

This ensures no public page is orphaned and the information architecture remains legible even with deep nesting.
